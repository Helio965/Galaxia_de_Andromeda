Use a placa de vídeo dedicada

O navegador está usando a GPU integrada. Em notebooks com duas placas de vídeo (por exemplo Intel/AMD + NVIDIA), o Windows costuma entregar a mais fraca ao navegador. A galáxia continua funcionando, mas com menos estrelas.

O navegador está desenhando a cena na CPU, sem usar a placa de vídeo. A galáxia foi reduzida ao mínimo para não travar.

Jeito mais fácil (Windows): feche esta janela e dê dois cliques em iniciar.bat. Ele abre o projeto numa janela do Chrome/Edge que pede a placa de alto desempenho.

Ou configure o navegador manualmente:

  1. No Chrome, em Configurações → Sistema, ligue Usar aceleração de gráficos quando disponível.
  2. No Windows, abra Configurações → Sistema → Tela → Elementos gráficos, escolha o Google Chrome → Opções → Alto desempenho → Salvar.
  3. Ou cole na barra de endereço chrome://flags/#force-high-performance-gpu , escolha Enabled e clique em Relaunch.
  4. Ligue o notebook na tomada e feche e abra o navegador de novo.

Deu certo quando o painel mostrar a placa dedicada com o ponto verde. No Microsoft Edge, use edge://flags.

Abra pelo servidor local

O navegador bloqueia os módulos JavaScript quando o index.html é aberto direto do disco (file://).

  1. Windows: dê dois cliques em iniciar.bat, na pasta do projeto.
  2. Qualquer sistema: rode python -m http.server 8000 na pasta e abra http://localhost:8000.
